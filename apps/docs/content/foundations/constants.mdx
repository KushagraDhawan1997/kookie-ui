Kookie UI's lengths come from one scale, shared with v2. Use these tokens in your own CSS so custom parts line up with the components.

## Space

Twelve steps: 2, 4, 8, 12, 16, 24, 32, 40, 48, 64, 96, 128px. Layout props (`p`, `m`, `gap` and the rest) take the step number. Only `Box`, `Flex` and `Grid` take `m`; other components leave the space around them to their parent.

```css
var(--space-1)  /* 2px */  …  var(--space-12) /* 128px */
var(--layout-space-1) … var(--layout-space-12) /* what gaps and layout props read */
```

## Roles

A component reads a role, never a raw step. Each role has one value per size, 1 to 4.

```css
var(--surface-p-1..4)      /* 16 24 32 40: padding of a card, dialog or Shell pane */
var(--panel-p-1..4)        /* 8 12 16 24: padding of a menu or notice */
var(--control-height-1..4) /* 28 32 40 48 */
var(--control-px-1..4)     /* 8 10 13 16: a control's side padding */
var(--control-px-pill-1..4)/* 12 14 17 20: the same, on a bare edge under a full radius */
var(--control-gap-1..4)    /* 4 8 8 12: between an icon and a label */
var(--icon-size-1..4)      /* 16 16 20 24 */
var(--row-inset-1..4)      /* 4 5 5 6: above and below a menu row's text */
var(--slot-inset-1..4)     /* 3 3 4 4: around a control hosted in another */
var(--overlay-w-1..4)      /* 360 440 560 720: dialog widths */
```

## Focus

```css
var(--focus-outline-width)  /* 2px */
var(--focus-outline-offset) /* 2px */
```
