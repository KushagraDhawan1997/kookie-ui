Docs Page lays out a single documentation page: a header with category, title, description and a "Copy page" button, a readable content column, and an optional table of contents that sticks to the side on large screens. Every page on this site uses it.

## Installation

<BlockInstallation />

## Usage

```tsx showLineNumbers
'use client';

import { DocsPage } from '@/components/blocks/docs-page/docs-page';
import { TableOfContents } from '@/components/blocks/table-of-contents/table-of-contents';
import Content from './content.mdx';

export default function ButtonPage() {
  return (
    <DocsPage
      meta={{
        title: 'Button',
        description: 'Trigger an action or event.',
        category: 'Components',
      }}
      tableOfContents={<TableOfContents />}
    >
      <Content />
    </DocsPage>
  );
}
```

The content column is marked with `data-content-area`. [Table of Contents](/docs/blocks/table-of-contents) reads headings from it, and "Copy page" copies its text.

## Anatomy

| File | Contains |
| ---- | -------- |
| `docs-page.tsx` | `DocsPage` and the `DocsPageMeta` type |
| `docs-page-header.tsx` | `DocsPageHeader`, built on [Page Header](/docs/blocks/page-header). Usable on its own |

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `meta` | `DocsPageMeta` | - | Title, description, category and source link for the header. |
| `header` | `ReactNode` | - | Replaces the generated header. |
| `headerActions` | `ReactNode` | - | Extra buttons beside the title. |
| `headerTabs` | `ReactNode` | - | Tabs under the header, e.g. Documentation and Examples. |
| `headerSeparator` | `boolean` | `false` | Separator under the header. Leave off when using tabs. |
| `headerContentGap` | Space scale | `'4'` | Gap between category, title and description. |
| `headerRootGap` | Space scale | `'4'` | Gap between the header and its tabs. |
| `tableOfContents` | `ReactNode` | - | Shown in a sticky column from the `lg` breakpoint. |
| `containerSize` | `'1' \| '2' \| '3' \| '4'` | `'3'` | Container size for the content. |
| `maxWidth` | `string` | `'48rem'` | Maximum width of the content column. |
| `contentGap` | Space scale | `'8'` | Gap between the header and the content. |
| `padding` | Space scale | `'4'` | Padding around the content. |
| `paddingX` | Space scale | - | Overrides horizontal padding. |
| `paddingY` | Space scale | `'6'` | Overrides vertical padding. |
| `contentPadding` | `{ initial?, sm? }` | `{ initial: '2', sm: '4' }` | Padding of the outer content area. |
| `outerMargin` | Space scale | `'6'` | Vertical margin of the whole page. |
| `showFooter` | `boolean` | `false` | Copyright line under the content. |
| `footerCopyright` | `{ name: string; url?: string }` | - | Copyright holder for the footer. |
| `githubUrl` | `string` | - | GitHub link in the footer. |

### DocsPageMeta

| Field | Type | Description |
| ----- | ---- | ----------- |
| `title` | `string` | Page title, rendered as the `h1`. |
| `description` | `string` | Shown under the title. |
| `category` | `string` | Shown above the title. |
| `source` | `string` | URL for a "View source" link. |

## Examples

### Site Defaults

Wrap `DocsPage` once with your site's footer and spacing, and use the wrapper everywhere. This site does this.

```tsx showLineNumbers
import { DocsPage, type DocsPageProps } from '@/components/blocks/docs-page/docs-page';

export function SiteDocsPage(props: DocsPageProps) {
  return (
    <DocsPage
      containerSize="2"
      headerContentGap="5"
      headerSeparator={!props.headerTabs}
      showFooter
      footerCopyright={{ name: 'Acme', url: 'https://acme.com' }}
      githubUrl="https://github.com/acme/docs"
      {...props}
    />
  );
}
```

## Accessibility

The title renders as the page's only `h1`. "Copy page" confirms with a changed label and icon once the text is on the clipboard.
