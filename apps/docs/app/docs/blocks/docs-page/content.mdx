Docs Page lays out a single documentation page: a header with the category and actions on one row, then the title, a lead and optional tabs; a reading column capped at a comfortable line length; and a table of contents that sticks beside it on large screens. Every page on this site uses it.

## Installation

<BlockInstallation />

## Usage

```tsx showLineNumbers
'use client';

import { DocsPage } from '@/components/blocks/docs-page/docs-page';
import { TableOfContents } from '@/components/blocks/table-of-contents/table-of-contents';
import Content from './content.mdx';

export default function ButtonPage() {
  return (
    <DocsPage
      meta={{
        title: 'Button',
        description: 'Trigger an action or event.',
        category: 'Components',
      }}
      tableOfContents={<TableOfContents />}
    >
      <Content />
    </DocsPage>
  );
}
```

The content column is marked with `data-content-area`. [Table of Contents](/docs/blocks/table-of-contents) reads headings from it, and "Copy page" copies its text.

## Anatomy

| File | Contains |
| ---- | -------- |
| `docs-page.tsx` | `DocsPage` and the `DocsPageMeta` type |
| `docs-page-header.tsx` | `DocsPageHeader`, built on [Page Header](/docs/blocks/page-header). Usable on its own |

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `meta` | `DocsPageMeta` | - | Category, title, description and source link for the header. |
| `header` | `ReactNode` | - | Replaces the generated header. |
| `headerActions` | `ReactNode` | - | Extra buttons in the header's action row, before "Copy page". |
| `headerTabs` | `ReactNode` | - | Tabs under the header, e.g. Documentation and Examples. They replace the header's rule. |
| `tableOfContents` | `ReactNode` | - | Shown in a sticky column from the `lg` breakpoint. |
| `maxWidth` | `string` | `'44rem'` | Width cap for the reading column, around 75 characters of body text. |
| `footer` | `{ name: string; url?: string; githubUrl?: string }` | - | Copyright line under the content. |

### DocsPageMeta

| Field | Type | Description |
| ----- | ---- | ----------- |
| `title` | `string` | Page title, rendered as the `h1`. |
| `description` | `string` | The lead under the title. |
| `category` | `string` | Shown at the start of the action row. |
| `source` | `string` | URL for a "Source" button in the action row. |

## Examples

### Site Defaults

Wrap `DocsPage` once with your footer and use the wrapper everywhere. This site does this.

```tsx showLineNumbers
import { DocsPage, type DocsPageProps } from '@/components/blocks/docs-page/docs-page';

const FOOTER = { name: 'Acme', url: 'https://acme.com', githubUrl: 'https://github.com/acme/docs' };

export function SiteDocsPage(props: DocsPageProps) {
  return <DocsPage {...props} footer={FOOTER} />;
}
```

### With Markdown

The page doesn't style its content. Render MDX inside [Markdown](/docs/blocks/markdown)'s `MarkdownContent` for type sizes and spacing that match the header.

## Accessibility

The title renders as the page's only `h1`. "Copy page" changes to "Copied" once the text is on the clipboard, and "Source" opens in a new tab.
