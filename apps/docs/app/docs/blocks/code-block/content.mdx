Code Block puts code in a quiet frame with a copy button. It highlights with [Shiki](https://shiki.style) at runtime, or frames markup that was already highlighted at build time, such as MDX processed by rehype-pretty-code. Long code collapses behind a "Show all" button, and longer snippets get line numbers.

Shiki loads the first time a runtime-highlighted block renders, so pages without code don't pay for it. Until it arrives the code shows as plain text, so nothing shifts when the colors land.

## Usage

```tsx
import { CodeBlock } from '@/components/blocks/code-block/code-block';

<CodeBlock code="npm install @kushagradhawan/kookie-ui" language="bash" />
```

To show a live demo above its code, use [Preview Block](/docs/blocks/preview-block) with its `code` prop.

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `code` | `string` | - | Raw code, highlighted at runtime. Use instead of `children`. |
| `language` | `string` | `'tsx'` | Shiki language for `code`. Read from the markup for `children`. |
| `children` | `ReactNode` | - | A pre-highlighted `<pre>`. Use instead of `code`. |
| `file` | `string` | - | File path shown in a header above the code. |
| `showLanguage` | `boolean` | `false` | Show the language in the header. |
| `showLineNumbers` | `boolean` | Automatic | Runtime code is numbered past five lines. Pre-highlighted code follows its markup. |
| `showCopy` | `boolean` | `true` | Show the copy button. It floats top-right, or sits in the header when there is one. |
| `collapsible` | `boolean` | `true` | Cap long code with a "Show all" button. |
| `collapsedHeight` | `number` | `400` | Height in pixels before code collapses. |
| `shikiConfig` | `ShikiConfig` | - | Themes, language aliases and transformers. Only applies to `code`. |
| `className` | `string` | - | Class on the frame. |

### ShikiConfig

| Field | Type | Default | Description |
| ----- | ---- | ------- | ----------- |
| `themes` | `{ light?: string; dark?: string }` | `github-light`, `github-dark` | Any bundled Shiki theme. Dark applies under `.dark`, `.dark-theme` or `[data-appearance="dark"]`. |
| `langAlias` | `Record<string, string>` | - | Maps your language names to Shiki's, e.g. `{ vue3: 'vue' }`. |
| `transformers` | `ShikiTransformer[]` | - | Shiki transformers for line highlights, diffs and similar. |
| `meta` | `string` | - | Meta string handed to transformers, e.g. `'{1,3-5}'`. |

### Styling

The frame reads these custom properties. Set them on `.code-block` or any ancestor.

| Property | Default |
| -------- | ------- |
| `--code-block-radius` | `var(--radius-surface-4)` |
| `--code-block-border` | `var(--gray-a4)` |
| `--code-block-background` | `var(--gray-a2)` |
| `--code-block-font-size` | `var(--font-size-2)` |
| `--code-block-line-height` | `1.7` |
| `--code-block-padding-x` | `var(--space-4)` |
| `--code-block-padding-y` | `var(--space-3)` |

### useCodeBlockContext

Returns `true` inside a `CodeBlock`. [Markdown](/docs/blocks/markdown) uses it to tell a highlighted block's `<code>` from inline code.

### MDX Code

Code fences highlighted by rehype-pretty-code arrive as a `<pre>`. [Markdown](/docs/blocks/markdown) frames them in a Code Block for you. Configure rehype-pretty-code with the same themes and `defaultColor: false`, so build-time and runtime code share one palette:

```ts showLineNumbers
const rehypePrettyCodeOptions = {
  theme: { light: 'github-light', dark: 'github-dark' },
  keepBackground: false,
  defaultColor: false,
};
```

Add `showLineNumbers` after a fence's language to number it, and `{2,4}` to highlight lines.

## Accessibility

The copy button is labelled "Copy code" and changes to "Copied" once the code is on the clipboard. "Show all" is a real button, so collapsed code can be expanded with the keyboard.
