Hero is the opening section of a landing page: an announcement, a headline, a line of supporting text and calls to action, optionally beside an image. Centered and stacked by default; split side by side on wider screens. The [home page](/) opens with one.

## Installation

<BlockInstallation />

## Usage

```tsx showLineNumbers
import { Hero } from '@/components/blocks/hero/hero';

<Hero.Root>
  <Hero.Title>Ship interfaces faster</Hero.Title>
  <Hero.Description>Accessible components with a design system built in.</Hero.Description>
  <Hero.Actions>
    <Button size="3" variant="classic" highContrast>Get started</Button>
  </Hero.Actions>
</Hero.Root>
```

## Anatomy

```tsx
<Hero.Root>
  <Hero.Meta />
  <Hero.Title />
  <Hero.Description />
  <Hero.Actions />
  <Hero.Media />
</Hero.Root>
```

## Props

Every part accepts the props of the component it wraps. Only the additions and changed defaults are listed.

| Part | Wraps | Adds or changes |
| ---- | ----- | --------------- |
| `Root` | `Flex` | `layout?: Responsive<'stacked' \| 'split'>` (`'stacked'`). `align="center"`, `gap="6"` |
| `Meta` | `Flex` | `gap="2"`, `align="center"` |
| `Title` | `Heading` | `size="9"`, `weight="medium"`, `align="center"` |
| `Description` | `Text` | `size="4"`, `align="center"` |
| `Actions` | `Flex` | `direction="row"`, `gap="2"`, `align="center"` |
| `Media` | `Flex` | - |

`stacked` sets `direction="column"`; `split` sets `direction="row"`. Pass `direction` to override either.

`Title` renders an `h1` by default through `Heading`. Keep one per page.

## Accessibility

Give `Media` images meaningful `alt` text, or an empty `alt` when they are decorative. Use links (`Button asChild` around your router link) for actions that navigate.
