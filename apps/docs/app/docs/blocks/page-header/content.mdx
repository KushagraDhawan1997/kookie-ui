Page Header is the top of a page: optional banner and avatar, a line of meta, the title, a description, actions and tabs. Each part is a thin wrapper over a Kookie UI primitive with sensible defaults, so any prop those primitives take still works.

## Installation

<BlockInstallation />

## Usage

```tsx showLineNumbers
import { PageHeader } from '@/components/blocks/page-header/page-header';

<PageHeader.Root separator>
  <PageHeader.Main>
    <PageHeader.Content>
      <PageHeader.Title>Projects</PageHeader.Title>
      <PageHeader.Description>Everything your team is working on.</PageHeader.Description>
    </PageHeader.Content>
    <PageHeader.Actions>
      <Button variant="classic">New project</Button>
    </PageHeader.Actions>
  </PageHeader.Main>
</PageHeader.Root>
```

## Anatomy

```tsx showLineNumbers
<PageHeader.Root>
  <PageHeader.Banner />
  <PageHeader.Main>
    <PageHeader.Media />
    <PageHeader.Content>
      <PageHeader.Meta />
      <PageHeader.Title />
      <PageHeader.Description />
    </PageHeader.Content>
    <PageHeader.Actions />
  </PageHeader.Main>
  <PageHeader.Tabs />
</PageHeader.Root>
```

## Props

Every part accepts the props of the component it wraps. Only the additions and changed defaults are listed.

| Part | Wraps | Adds or changes |
| ---- | ----- | --------------- |
| `Root` | `Flex` | `separator?: boolean` draws a line underneath. `direction="column"`, `gap="4"` |
| `Banner` | `Box` | `src: string`, `alt?: string`, `height?: string` (`'200px'`). A cover image with rounded corners |
| `Main` | `Flex` | `layout?: Responsive<'inline' \| 'stacked'>` (`'inline'`). `align="center"`, `justify="between"`, `gap="4"` |
| `Media` | `Avatar` | `type?: 'logo' \| 'avatar'` (`'avatar'`), `overlap?: boolean`. `size="6"` |
| `Content` | `Flex` | `direction="column"`, `gap="2"`, `flexGrow="1"` |
| `Meta` | `Flex` | `gap="2"`, `align="center"`, `wrap="wrap"` |
| `Title` | `Heading` | `as="h1"`, `size="9"`, `weight="medium"` |
| `Description` | `Text` | `size="4"`, `emphasis="medium"` |
| `Actions` | `Flex` | `gap="2"`, `align="center"` |
| `Tabs` | `Flex` | `direction="column"`, `width="100%"` |

`Media` with `type="logo"` is square-cornered; `avatar` is round. `overlap` pulls an avatar up over a `Banner`, and does nothing without one.

## Accessibility

`Title` renders an `h1` by default; pass `as="h2"` when the header sits below another `h1`. `Banner` has `role="img"` and uses `alt` as its label; pass an empty `alt` when the image is decorative.
