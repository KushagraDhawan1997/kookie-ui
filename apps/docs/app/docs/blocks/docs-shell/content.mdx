Docs Shell is the frame of a documentation site: a searchable sidebar built from a navigation config, beside the page content, with a toolbar across the top of the content. On small screens the sidebar becomes an overlay opened from the toolbar's first button. It is built on Kookie UI's `Shell`, `Sidebar` and `Toolbar`.

This site runs on it. The sidebar to the left is a Docs Shell.

## Usage

Describe the navigation once, then wrap your docs layout.

```tsx showLineNumbers
// navigation.ts
import type { DocsNavigationConfig } from '@/components/blocks/docs-shell/types';

export const navigation: DocsNavigationConfig = {
  groups: [
    {
      label: 'Get Started',
      items: [{ href: '/docs/installation', title: 'Installation' }],
    },
    {
      label: 'Components',
      items: [
        { href: '/docs/button', title: 'Button', badge: 'New' },
        { href: '/docs/card', title: 'Card' },
      ],
    },
  ],
};
```

```tsx showLineNumbers
// app/docs/layout.tsx
'use client';

import Link from 'next/link';
import { usePathname } from 'next/navigation';
import { DocsShell } from '@/components/blocks/docs-shell/docs-shell';
import { navigation } from '@/navigation';

export default function DocsLayout({ children }: { children: React.ReactNode }) {
  return (
    <DocsShell
      navigation={navigation}
      logo={{ src: '/logo.png', alt: 'Acme' }}
      pathname={usePathname()}
      linkComponent={Link}
    >
      {children}
    </DocsShell>
  );
}
```

## Anatomy

| File | Contains |
| ---- | -------- |
| `docs-shell.tsx` | `DocsShell`: the `Shell` layout, and a floating header over the page's `Shell.Scroll` holding the toolbar, with the sidebar button and a `ToolbarSlot` for the page's actions |
| `docs-sidebar.tsx` | `DocsSidebar`: a floating header with the logo and search, the grouped menu, and a floating footer. Usable on its own inside any `Shell.Sidebar` |
| `types.ts` | Navigation, logo and link types |

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `navigation` | `DocsNavigationConfig` | - | Groups and items for the sidebar. |
| `pathname` | `string` | `''` | Current path. The matching item is marked active. |
| `linkComponent` | `DocsLinkComponent` | `<a>` | Your router's link, such as `next/link`. |
| `hero` | `ReactNode` | - | A band at the top of the content pane, edge to edge. The toolbar floats over it. |
| `toolbar` | `ReactNode` | - | Controls at the end of the toolbar: `ToolbarGroup`s, `ToolbarButton`s or a `ToolbarOverflow`. The page's own actions follow them. |
| `logo` | `DocsLogoConfig` | - | Logo in the sidebar header. |
| `headerActions` | `ReactNode` | - | Beside the logo, e.g. a version badge. |
| `sidebarFooter` | `ReactNode` | - | The floating footer toolbar's contents, e.g. a theme switch. |
| `sidebarResizable` | `boolean` | `true` | Let people drag the sidebar edge. |
| `mobileTriggerIcon` | `ReactNode` | Sidebar icon | Icon for the sidebar button at the start of the toolbar. |
| `height` | `Shell.Root` height | - | Height of the shell. Leave it unset for an app frame, so the page scrolls on a phone. A value makes the shell contained. |

### Navigation Item

| Field | Type | Description |
| ----- | ---- | ----------- |
| `href` | `string` | Link target. Also the key, so keep it unique. |
| `title` | `string` | Label. Search matches against it. |
| `icon` | `IconSvgElement \| ComponentType \| ReactElement` | Optional. A HugeIcons icon, a component or an element. |
| `badge` | `string \| Sidebar.BadgeConfig` | Optional text badge, or a config for color and variant. |
| `items` | `DocsNavigationItem[]` | Optional nested pages, shown in a collapsible sub-menu that opens when one is active. |

### Logo

| Field | Type | Default | Description |
| ----- | ---- | ------- | ----------- |
| `src` | `string` | - | Image URL. Ignored when `label` is set. |
| `label` | `string` | - | A text wordmark instead of an image. |
| `alt` | `string` | - | Accessible name. Its first letter is the image fallback. |
| `href` | `string` | `'/'` | Where the logo links. |
| `size` | `'1'` – `'5'` | `'3'` | Image size. |

## Examples

### Status Badges

```tsx
{
  href: '/docs/combobox',
  title: 'Combobox',
  badge: { content: 'Alpha', size: '1', color: 'gray' },
}
```

### Toolbar

Pass your own controls with `toolbar`. Wrap them in `ToolbarOverflow` and the ones that don't fit move into a More menu on small screens.

```tsx showLineNumbers
<DocsShell
  navigation={navigation}
  toolbar={
    <ToolbarOverflow label="More actions">
      <ToolbarGroup>
        <ToolbarButton asChild iconOnly aria-label="GitHub">
          <a href="https://github.com/acme/docs">
            <HugeiconsIcon icon={GithubIcon} strokeWidth={1.75} />
          </a>
        </ToolbarButton>
      </ToolbarGroup>
    </ToolbarOverflow>
  }
>
  {children}
</DocsShell>
```

A page adds its own controls with `ToolbarFill`. [Docs Page](/docs/blocks/docs-page) puts its Source button there.

```tsx
<ToolbarFill name={DOCS_PAGE_ACTIONS}>
  <ToolbarButton>Edit</ToolbarButton>
</ToolbarFill>
```

### Nested Pages

```tsx showLineNumbers
{
  href: '/docs/forms',
  title: 'Forms',
  items: [
    { href: '/docs/forms/validation', title: 'Validation' },
    { href: '/docs/forms/submission', title: 'Submission' },
  ],
}
```

## Accessibility

Search filters the menu as you type and shows a flat list of matches. The logo link and the sidebar button have accessible names. Active items are marked through `Sidebar.MenuButton`, which sets `aria-current`.

The toolbar is one tab stop. The arrow keys move between its controls, including the ones a page adds through `ToolbarFill`.
