Preview Block frames a live demo: a toolbar with a light/dark switch, a padded stage, and optionally the demo's source attached underneath, all in one outline. Every example on this site is one. The stage has its own `Theme`, so switching a preview to dark leaves the page alone.

## Installation

<BlockInstallation />

## Usage

```tsx
import { PreviewBlock } from '@/components/blocks/preview-block/preview-block';

<PreviewBlock code={`<Button variant="classic" highContrast>Save</Button>`}>
  <Button variant="classic" highContrast>Save</Button>
</PreviewBlock>
```

In MDX you can also follow a `PreviewBlock` with a code fence. [Markdown](/docs/blocks/markdown) joins the two into one frame, as on this page.

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `code` | `string` | - | Source shown under the stage, in the same frame. |
| `language` | `string` | `'tsx'` | Language for `code`. |
| `codeProps` | `CodeBlockProps` | - | Extra [Code Block](/docs/blocks/code-block) options for `code`, such as `file`. |
| `background` | `'none' \| 'dots' \| 'grid' \| CSSProperties` | `'dots'` | A preset pattern, or your own styles for the stage. |
| `patternSize` | `number` | `20` | Spacing of the dots or grid lines, in pixels. |
| `patternColor` | `string` | `--gray-a5` (dots), `--gray-a3` (grid) | Pattern color. |
| `height` | `string` | - | Fixed stage height, for demos that fill their container. Without it the stage fits its content, at least `10rem` tall. |
| `appearance` | `'light' \| 'dark'` | Page's | Starting appearance of the stage. |
| `showThemeToggle` | `boolean` | `true` | Show the light/dark switch. |
| `label` | `ReactNode` | - | Text on the left of the toolbar. |
| `fontFamily` | `'sans' \| 'mono' \| 'serif'` | `'sans'` | Font for the stage. |
| `className` | `string` | - | Class on the frame. |

The toolbar only renders when there is a switch or a label.

### Styling

| Property | Default |
| -------- | ------- |
| `--preview-block-radius` | `var(--radius-surface-4)` |
| `--preview-block-border` | `var(--gray-a4)` |
| `--preview-block-padding` | `var(--space-6)`, `var(--space-4)` on small screens |
| `--preview-block-min-height` | `10rem` |

## Examples

### Grid Stage

A grid suits layout demos, where alignment matters.

<PreviewBlock background="grid" label="Storage card" code={previewSources.grid}>
  <Card variant="classic" size="2">
    <Flex direction="column" gap="1" width="240px">
      <Text size="2" weight="medium">Storage</Text>
      <Text size="2" color="gray">18.4 GB of 50 GB used</Text>
    </Flex>
  </Card>
</PreviewBlock>

### Fixed Dark Stage

Pin the stage to dark and hide the switch when a demo only makes sense one way.

<PreviewBlock appearance="dark" showThemeToggle={false} code={previewSources.dark}>
  <Flex gap="2" align="center">
    <Badge color="green" variant="soft">Live</Badge>
    <Text size="2">Deployed 2 minutes ago</Text>
  </Flex>
</PreviewBlock>

### Custom Background

Pass styles instead of a preset for gradients or images.

<PreviewBlock
  showThemeToggle={false}
  background={{ backgroundImage: 'linear-gradient(135deg, var(--iris-4), var(--pink-4))' }}
  code={previewSources.gradient}
>
  <Button variant="soft" highContrast material="translucent">Action</Button>
</PreviewBlock>

## Accessibility

The light/dark switch is a segmented control whose options are labelled "Light preview" and "Dark preview". The demo keeps its own semantics.
