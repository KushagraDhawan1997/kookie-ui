Preview Block frames a live demo on a dotted, gridded or custom background, with a light/dark switch in the corner. Every example on this site sits in one. It sets its own `Theme`, so switching the preview to dark leaves the rest of the page alone.

<BlockInstallation />

## Usage

```tsx
import { PreviewBlock } from '@/components/blocks/preview-block/preview-block';
import { Button } from '@kushagradhawan/kookie-ui';

export function ButtonDemo() {
  return (
    <PreviewBlock>
      <Button variant="classic" highContrast>Save</Button>
    </PreviewBlock>
  );
}
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `background` | `'none' \| 'dots' \| 'grid' \| CSSProperties` | `'dots'` | A preset pattern, or your own styles for the stage. |
| `patternSize` | `number` | `24` | Spacing of the dots or grid lines, in pixels. |
| `patternColor` | `string` | `--gray-a6` (dots), `--gray-a3` (grid) | Pattern color. |
| `width` | `string` | - | Stage width. |
| `height` | `string` | - | Stage height. Without it the stage is at least `240px` tall. |
| `variant` | `'surface' \| 'classic' \| 'soft' \| 'ghost'` | `'soft'` | Card variant for the frame. |
| `appearance` | `'light' \| 'dark' \| 'inherit'` | `'inherit'` | Starting appearance of the preview. |
| `showThemeToggle` | `boolean` | `true` | Show the light/dark switch. |
| `fontFamily` | `'sans' \| 'mono' \| 'serif'` | `'sans'` | Font for the preview. |
| `p`, `px`, `py`, `pt`, `pr`, `pb`, `pl` | Space scale | `p="2"` | Padding inside the frame. |
| `m`, `mx`, `my`, `mt`, `mr`, `mb`, `ml` | Space scale | `my="3"` | Margin around the frame. |

## Examples

### Grid Stage

A grid suits layout demos, where alignment matters.

<PreviewBlock background="grid" height="16rem">
  <Card variant="classic" size="2">
    <Flex direction="column" gap="2" width="240px">
      <Text size="2" weight="medium">Storage</Text>
      <Text size="2" color="gray">18.4 GB of 50 GB used</Text>
    </Flex>
  </Card>
</PreviewBlock>

```tsx
<PreviewBlock background="grid" height="16rem">
  <Card variant="classic" size="2">...</Card>
</PreviewBlock>
```

### Fixed Dark Preview

Pin the preview to dark and hide the switch when a demo only makes sense one way.

<PreviewBlock appearance="dark" showThemeToggle={false} height="12rem">
  <Flex gap="2" align="center">
    <Badge color="green" variant="soft">Live</Badge>
    <Text size="2">Deployed 2 minutes ago</Text>
  </Flex>
</PreviewBlock>

```tsx
<PreviewBlock
  appearance="dark"
  showThemeToggle={false}
  height="12rem"
>
  ...
</PreviewBlock>
```

### Custom Background

Pass styles instead of a preset for gradients or images.

<PreviewBlock
  height="12rem"
  showThemeToggle={false}
  background={{
    backgroundImage: 'linear-gradient(135deg, var(--iris-4), var(--pink-4))',
    borderRadius: 'var(--radius-3)',
  }}
>
  <Button variant="soft" highContrast material="translucent">Action</Button>
</PreviewBlock>

## Accessibility

The light/dark switch is a segmented control; each option has a label ("Light preview", "Dark preview"). The preview content keeps its own semantics.
