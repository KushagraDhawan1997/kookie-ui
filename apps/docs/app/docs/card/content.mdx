Card is a versatile container component for grouping related content. It provides consistent styling, spacing, and visual hierarchy through its variant and size props.

This is an enhanced version of the Card from [Radix Themes](https://www.radix-ui.com/themes/docs/components/card).

## Usage

```tsx
import { Card, Text, Heading, Flex, Button } from '@kushagradhawan/kookie-ui';

export function MyCard() {
  return (
    <Card>
      <Flex direction="column" gap="3">
        <Heading size="3">Card Title</Heading>
        <Text size="2">Card content goes here.</Text>
        <Button size="2">Action</Button>
      </Flex>
    </Card>
  );
}
```

## Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `size` | `'1' \| '2' \| '3' \| '4'` | `'2'` | Padding and corner. Unset, it follows the Theme size. Supports responsive values. |
| `variant` | `'surface' \| 'outline' \| 'raised' \| 'ghost' \| 'soft'` | `'raised'` | The visual style of the card. |
| `asChild` | `boolean` | `false` | Merge props onto the child element using Radix Slot. |

## Variants

### Surface

A subtle elevated card with a light background.

```tsx
<Card variant="surface">
  <Text>Surface variant with subtle elevation</Text>
</Card>
```

### Outline

A visible border.

```tsx
<Card variant="outline">
  <Text>Outline variant with visible border</Text>
</Card>
```

### Raised

A solid, opaque card with subtle shadow.

```tsx
<Card variant="raised">
  <Text>Raised variant with solid background</Text>
</Card>
```

### Ghost

No visible container, useful for grouping content without visual boundaries.

```tsx
<Card variant="ghost">
  <Text>Ghost variant with no visible container</Text>
</Card>
```

### Soft

A muted background with no border.

```tsx
<Card variant="soft">
  <Text>Soft variant with muted background</Text>
</Card>
```

## Sizes

Sizes 1 to 4 set the padding (16, 24, 32, 40px) and the corner. Unset, a Card follows the Theme size.

```tsx
<Flex direction="column" gap="5">
  <Card size="1"><Text>Size 1</Text></Card>
  <Card size="2"><Text>Size 2 - Default</Text></Card>
  <Card size="3"><Text>Size 3</Text></Card>
  <Card size="4"><Text>Size 4</Text></Card>
</Flex>
```

## Bleed

`bleed` on any margin prop pulls a child out by the Card's padding, so it reaches the Card's edge. The Card clips it to its corner.

```tsx
<Card>
  <Box mx="bleed" mt="bleed" mb="4">
    <img src="/image.jpg" alt="Full bleed image" style={{ display: 'block', width: '100%' }} />
  </Box>
  <Text>Caption</Text>
</Card>
```

## Nesting

A Card inside a Card draws its corner as the outer corner minus the outer padding, never below 0.

## Interactive Cards

Use `asChild` to make the entire card interactive.

```tsx
import { Link } from 'react-router-dom';

<Card asChild>
  <Link to="/details">
    <Flex direction="column" gap="3">
      <Heading size="3">Clickable Card</Heading>
      <Text size="2">Click anywhere to navigate</Text>
    </Flex>
  </Link>
</Card>
```
