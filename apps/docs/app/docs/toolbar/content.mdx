Toolbar is a row of controls that counts as one tab stop. Tab moves into it, the arrow keys move between its controls, and Tab moves out. It is built on [Radix Toolbar](https://www.radix-ui.com/primitives/docs/components/toolbar).

For the bar at the top of an app, use `Shell.Header`.

## Usage

```tsx showLineNumbers
import { Flex, Toolbar } from '@kushagradhawan/kookie-ui';

export function EditorToolbar() {
  return (
    <Toolbar aria-label="Formatting">
      <Toolbar.Title>Notes</Toolbar.Title>
      <Flex gap="2" align="center">
        <Toolbar.Group aria-label="Text style">
          <Toolbar.Button iconOnly aria-label="Bold" aria-pressed={bold}>
            <HugeiconsIcon icon={TextBoldIcon} strokeWidth={1.75} />
          </Toolbar.Button>
        </Toolbar.Group>
        <Toolbar.Separator />
        <Toolbar.Button>Share</Toolbar.Button>
      </Flex>
    </Toolbar>
  );
}
```

The row spaces its direct children apart. Put controls that belong together in a `Flex`.

## Parts

| Part | Description |
| ---- | ----------- |
| `Toolbar` | The row. Takes `size` (`'1'`–`'4'`, default `'2'`), `orientation` (`'horizontal'` or `'vertical'`), `backdrop` and `aria-label`. |
| `Toolbar.Button` | Takes every Button prop. Set `iconOnly` with an `aria-label` for an icon button. Set `aria-pressed` for a toggle. |
| `Toolbar.Group` | A quiet gray well around related buttons. `disabled` turns them all off. |
| `Toolbar.Separator` | A hairline between clusters. |
| `Toolbar.Title` | One truncating line at the leading edge. |

Buttons rest as gray `soft`, or gray `ghost` inside a group, and take the toolbar's size. A `size`, `variant` or `color` you set wins.

Set `backdrop` when content passes behind the row, as in a floating `Shell.PaneHeader`. Buttons then rest `raised` and a group's well is raised too, so each control has a surface of its own.

## Accessibility

- The row is `role="toolbar"` and needs an `aria-label`.
- Arrow keys move focus and wrap at the ends: Left and Right when horizontal, Up and Down when vertical.
- `Toolbar.Button` throws outside a `Toolbar`.
