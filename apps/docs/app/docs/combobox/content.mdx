A searchable dropdown that combines select functionality with powerful filtering. Perfect for finding options in large lists, building command palettes, or when users need quick access through search.

Built on top of [cmdk](https://cmdk.paco.me/) for search and filtering, and [Radix Popover](https://www.radix-ui.com/primitives/docs/components/popover) for positioning and focus management.

## Usage

The trigger shows `displayValue` for the selected value. Without it, the trigger shows the raw `value` (for example `apple`, not `Apple`).

```tsx
import { Combobox } from '@kushagradhawan/kookie-ui';

const fruits = [
  { value: 'apple', label: 'Apple' },
  { value: 'banana', label: 'Banana' },
  { value: 'cherry', label: 'Cherry' },
];

// Module scope keeps the function stable across renders
const getFruitLabel = (value: string | null) => fruits.find((fruit) => fruit.value === value)?.label;

export function FruitPicker() {
  return (
    <Combobox.Root displayValue={getFruitLabel}>
      <Combobox.Trigger aria-label="Fruit">
        <Combobox.Value placeholder="Select a fruit" />
      </Combobox.Trigger>
      <Combobox.Content>
        <Combobox.Input placeholder="Search fruits..." />
        <Combobox.List>
          {fruits.map((fruit) => (
            <Combobox.Item key={fruit.value} value={fruit.value}>
              {fruit.label}
            </Combobox.Item>
          ))}
          <Combobox.Empty>No fruits found</Combobox.Empty>
        </Combobox.List>
      </Combobox.Content>
    </Combobox.Root>
  );
}
```

## Anatomy

Combobox is a compound component with the following parts:

```tsx
<Combobox.Root>
  <Combobox.Trigger>
    <Combobox.Value />
  </Combobox.Trigger>
  <Combobox.Content>
    <Combobox.Input />
    <Combobox.List>
      <Combobox.Group>
        <Combobox.Label />
        <Combobox.Item />
      </Combobox.Group>
      <Combobox.Separator />
      <Combobox.Empty />
    </Combobox.List>
  </Combobox.Content>
</Combobox.Root>
```

## Root Props

The Root component manages state and provides context to all child components.

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `size` | `'1' \| '2' \| '3'` | Combobox density: 1 (24px) for toolbars, 2 (32px) for standard forms, 3 (40px) for prominent selections. Supports responsive objects |
| `value` | `string \| null` | Controlled selection value |
| `defaultValue` | `string \| null` | Initial selection value for uncontrolled usage |
| `onValueChange` | `(value: string \| null) => void` | Callback fired when selection changes |
| `open` | `boolean` | Controlled open state |
| `defaultOpen` | `boolean` | Initial open state |
| `onOpenChange` | `(open: boolean) => void` | Callback fired when dropdown opens/closes |
| `placeholder` | `string` | Text shown when no option is selected (default: "Select an option") |
| `searchPlaceholder` | `string` | Placeholder for search input (default: "Search...") |
| `searchValue` | `string` | Controlled search input value |
| `defaultSearchValue` | `string` | Initial search value |
| `onSearchValueChange` | `(value: string) => void` | Callback fired when search changes |
| `shouldFilter` | `boolean` | Enable built-in fuzzy search (default: true) |
| `filter` | `(value, search, keywords) => number` | Custom filter function. Returns 0-1 where 0 is no match, 1 is exact match |
| `loop` | `boolean` | Allow keyboard navigation to cycle through options (default: true) |
| `disabled` | `boolean` | Prevents all interaction with the combobox |
| `resetSearchOnSelect` | `boolean` | Clear the search when an option is selected (default: true) |
| `resetSearchOnClose` | `boolean` | Clear the search when the popup is dismissed without a selection (default: true) |
| `color` | `AccentColor` | Semantic color for the trigger and selected items |
| `displayValue` | `string \| ((value) => string \| undefined)` | Text shown in the trigger for the selected value. Without it the raw value is shown. Pass a stable function (module scope or `useCallback`); an inline function runs on every render |

## Trigger Props

The Trigger component renders as a button that opens the dropdown.

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `variant` | `'classic' \| 'surface' \| 'soft' \| 'outline' \| 'ghost'` | Trigger button style: classic for elevated, surface for standard fields, outline for bordered, soft for subtle, ghost for minimal |
| `color` | `AccentColor` | Semantic color. Overrides color from Root if provided |
| `radius` | `'none' \| 'small' \| 'medium' \| 'large' \| 'full'` | Corner radius scale |
| `material` | `'solid' \| 'translucent'` | Trigger background: solid for opaque, translucent for depth over images |
| `panelBackground` | `'solid' \| 'translucent'` | Deprecated: Use material instead |
| `loading` | `boolean` | Shows a spinner, sets `aria-busy`, and keeps the popup from opening. The trigger stays focusable |
| `error` | `boolean` | Visual error state and `aria-invalid`, typically for validation failures |
| `readOnly` | `boolean` | Shows the value and sets `aria-readonly`. The popup does not open |
| `disabled` | `boolean` | Prevents interaction. Overrides Root disabled if provided |
| `width` | `string` | Trigger width (CSS value) |
| `placeholder` | `string` | Override placeholder from Root |
| `aria-label` | `string` | Accessible name. The trigger needs one of `aria-label`, `aria-labelledby`, or a `<label htmlFor>` |

Trigger also supports all margin props (`m`, `mx`, `my`, `mt`, `mr`, `mb`, `ml`) with responsive values.

## Content Props

The Content component renders the dropdown surface containing the search input and options list.

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `variant` | `'solid' \| 'soft'` | Content surface style: solid for opaque standard background, soft for subtle content-heavy interfaces |
| `size` | `'1' \| '2' \| '3'` | Override size from Root. Affects padding and item height |
| `color` | `AccentColor` | Semantic color for items. Falls back to Root color, then theme accent |
| `material` | `'solid' \| 'translucent'` | Surface background. Falls back to the Theme material |
| `panelBackground` | `'solid' \| 'translucent'` | Deprecated: Use material instead |
| `width`, `minWidth`, `maxWidth` | `string` | Surface width. `minWidth` defaults to the trigger width, `maxWidth` to 480px |
| `aria-label` | `string` | Accessible name for the popup, search field and list. Defaults to the trigger's name |
| `container` | `HTMLElement` | Portal container. Defaults to `document.body` |
| `forceMount` | `boolean` | Keep content mounted while closed. Last resort: closed content keeps its positioning and dismiss listeners running. Use `displayValue` on Root instead |

## Input Props

The Input component renders the search field inside Content.

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `variant` | `'classic' \| 'surface' \| 'soft' \| 'outline' \| 'ghost'` | Input field style. Defaults to 'surface' for solid Content, 'soft' for soft Content |
| `placeholder` | `string` | Search input placeholder. Overrides searchPlaceholder from Root |
| `startAdornment` | `ReactNode` | Icon or element before input (e.g., search icon) |
| `endAdornment` | `ReactNode` | Icon or element after input |
| `value` | `string` | Override controlled search value from Root |
| `onValueChange` | `(value: string) => void` | Override search change handler from Root |

## Item Props

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `value` | `string` | Value passed to `onValueChange`. Without it, the item's text is used |
| `label` | `string` | Text matched by search. Defaults to the text of the children. Set it when the children are components whose text is not written in the JSX |
| `keywords` | `string[]` | Extra search terms |
| `disabled` | `boolean` | Skips the item in keyboard navigation and blocks selection |
| `onSelect` | `(value: string) => void` | Called when the item is selected |

Search matches the item's visible text, its `value`, and its `keywords`.

## Other Components

- **`Combobox.Value`** - Shows `displayValue`, else the raw selected value, else the placeholder
- **`Combobox.List`** - Scrollable listbox that holds the items. `label` overrides its accessible name
- **`Combobox.Group`** - Groups related items together
- **`Combobox.Label`** - Non-interactive heading. Inside a Group, it names the group for screen readers
- **`Combobox.Separator`** - Visual separator between items or groups
- **`Combobox.Empty`** - Shown when no results match search. Only visible when filtering produces zero matches

        </Combobox.List>

## Custom Filtering

### Disable Built-in Filtering

For server-side search, disable the built-in filtering and fetch options with a data library such as React Query.

```tsx
import { useQuery, keepPreviousData } from '@tanstack/react-query';

function AsyncCombobox() {
  const [searchValue, setSearchValue] = React.useState('');
  const deferredSearch = React.useDeferredValue(searchValue);

  const { data: options = [], isFetching } = useQuery({
    queryKey: ['options', deferredSearch],
    queryFn: () => fetchOptions(deferredSearch), // your typed API client
    placeholderData: keepPreviousData,
  });

  return (
    <Combobox.Root
      size="2"
      shouldFilter={false}
      searchValue={searchValue}
      onSearchValueChange={setSearchValue}
    >
      <Combobox.Trigger variant="surface" aria-label="Option">
        <Combobox.Value placeholder="Search..." />
      </Combobox.Trigger>
      <Combobox.Content>
        <Combobox.Input placeholder="Type to search..." />
        <Combobox.List>
          {options.map((option) => (
            <Combobox.Item key={option.id} value={option.id}>
              {option.label}
            </Combobox.Item>
          ))}
          <Combobox.Empty>{isFetching ? 'Searching...' : 'No results'}</Combobox.Empty>
        </Combobox.List>
      </Combobox.Content>
    </Combobox.Root>
  );
}
```

### Custom Filter Function

Provide custom ranking logic for more control over search results. The item's visible text is passed as the first keyword.

```tsx
const customFilter = (value: string, search: string, keywords?: string[]) => {
  const searchLower = search.toLowerCase();
  const terms = [value, ...(keywords ?? [])].map((term) => term.toLowerCase());

  // Exact match gets highest score
  if (terms.some((term) => term === searchLower)) return 1;

  // Starts with search gets high score
  if (terms.some((term) => term.startsWith(searchLower))) return 0.8;

  // Contains search gets medium score
  if (terms.some((term) => term.includes(searchLower))) return 0.5;

  return 0; // No match
};

<Combobox.Root size="2" filter={customFilter}>
  <Combobox.Trigger variant="surface" aria-label="Library">
    <Combobox.Value placeholder="Select..." />
  </Combobox.Trigger>
  <Combobox.Content>
    <Combobox.Input placeholder="Search..." />
    <Combobox.List>
      <Combobox.Item value="react" keywords={['library', 'ui', 'frontend']}>
        React
      </Combobox.Item>
      <Combobox.Item value="vue" keywords={['framework', 'ui', 'frontend']}>
        Vue
      </Combobox.Item>
    </Combobox.List>
  </Combobox.Content>
</Combobox.Root>
```

## Accessibility

The trigger follows the WAI-ARIA combobox pattern with a dialog popup. The popup holds a search field (itself a combobox) that controls the listbox of options.

### Labelling

The combobox role does not take its name from its content, so the trigger needs a label. Use `aria-label`, `aria-labelledby`, or a `<label htmlFor>` pointing at the trigger. The same name labels the popup, the search field and the listbox. In development, an unlabelled trigger logs a warning.

```tsx
<Flex direction="column" gap="1">
  <Text as="label" size="2" weight="medium" htmlFor="country">
    Country
  </Text>
  <Combobox.Root size="2">
    <Combobox.Trigger id="country" variant="surface">
      <Combobox.Value placeholder="Select country" />
    </Combobox.Trigger>
    <Combobox.Content>
      <Combobox.Input placeholder="Search..." />
      <Combobox.List>
        <Combobox.Item value="us">United States</Combobox.Item>
        <Combobox.Item value="uk">United Kingdom</Combobox.Item>
      </Combobox.List>
    </Combobox.Content>
  </Combobox.Root>
</Flex>
```

### Keyboard Navigation

- **Space/Enter/Arrow Down** - Open the dropdown when the trigger is focused
- **Type** - Filter options in real time
- **Arrow Down/Up** - Move the highlight through options
- **Home/End** - Jump to first/last option
- **Enter** - Select the highlighted option and close
- **Escape** - Close without selecting
- **Tab** - Close the dropdown and move focus to the next element

When the dropdown opens, the highlight starts on the selected option. Without a `Combobox.Input`, focus moves to the list so the keys above still work.

### ARIA Attributes

- `role="combobox"` with `aria-haspopup="dialog"`, `aria-expanded` and `aria-controls` on the trigger
- `aria-invalid`, `aria-busy`, `aria-readonly` and `aria-disabled` follow the `error`, `loading`, `readOnly` and `disabled` props
- The search field has `aria-controls` pointing at the listbox and `aria-activedescendant` pointing at the highlighted option
- `aria-selected` marks the highlighted option; `aria-checked` marks the chosen option

### Screen Readers

- The number of matching results, or "No results", is announced after typing pauses
- The chosen option is exposed with `aria-checked`
- Group labels name their groups
- The loading state is exposed with `aria-busy`

### Focus Management

- The search field receives focus when the dropdown opens
- Focus returns to the trigger when the dropdown closes
- In Windows High Contrast mode, the highlighted option shows a system outline
