## Code in this package

### Radix Themes

Womp UI began as a fork of [Radix Themes](https://github.com/radix-ui/themes) by WorkOS. The prop system, the layout components, the colour and token structure, and six small icons (the check, the dot, the divider and the chevrons in `src/components/icons.tsx`) come from it.

MIT License. Copyright (c) 2023 WorkOS. The full text is in `LICENSE`.

### Lucide and Feather

## Libraries it is built on

These are installed as dependencies, not copied. Each keeps its own licence in its own package.

| Library | What Womp UI uses it for | By | Licence |
| --- | --- | --- | --- |
| [Radix Primitives](https://www.radix-ui.com/primitives) (`radix-ui`) | The behaviour under dialogs, menus, popovers, selects, tabs and most other components | WorkOS | MIT |
| [Radix Colors](https://www.radix-ui.com/colors) (`@radix-ui/colors`) | The colour scales | Radix (WorkOS) | MIT |
| [shadcn/ui](https://ui.shadcn.com) (`@shadcn/react`) | `MessageScroller`: following a streamed reply, anchoring a turn and keeping the reader's place are shadcn's Message Scroller | shadcn | MIT |
| [cmdk](https://github.com/pacocoursey/cmdk) | `Command` and `Combobox`: filtering and keyboard handling | Paco Coursey | MIT |
| [TanStack Virtual](https://tanstack.com/virtual) (`@tanstack/react-virtual`) | `VirtualMenu`: drawing only the rows in view | Tanner Linsley | MIT |
| [react-dropzone](https://github.com/react-dropzone/react-dropzone) | `Chatbar`: dropping and picking files | Param Aggarwal | MIT |
| [classnames](https://github.com/JedWatson/classnames) | Joining class names | Jed Watson | MIT |
| [Zod](https://zod.dev) | The component schemas | Colin McDonnell | MIT |
